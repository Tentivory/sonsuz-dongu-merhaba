# Sonsuz Döngü Merhaba

## Bu Nedir?

Bu proje, insanlığın en derin sorusunu yanıtlar: **"Kaç kez merhaba diyebilirsin?"**

Cevap: Sonsuz. Veya bilgisayar çökene kadar. Bu kod, durmadan merhaba der. Neden? Çünkü yapabilir.

### Uyarı

Bu kodu çalıştırırsanız, terminaliniz sonsuza kadar meşgul olur. Sorumluluk size aittir. Biz sadece arayız.

## Kullanım

```bash
python merhaba.py
```

Ctrl+C ile durdurabilirsiniz. Veya durduramayabilirsiniz. Şans.
